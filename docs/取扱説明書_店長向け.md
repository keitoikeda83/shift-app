# 取扱説明書（店長向け）

シフト管理アプリ「Shift Manager」の店長（管理者）向け取扱説明書です。
従業員から提出されたシフト希望の確認・調整・確定、シフト表の出力までの一連の操作を説明します。

---

## 1. シフトの状態モデル

このアプリでは、シフトを以下の 3 段階で管理します。タブやセルの色分けはこの状態に対応しています。

| 状態 | 色 | 意味 |
| --- | --- | --- |
| **未確定（pending）** | 赤系 | 従業員が申請したばかり。店長未対応 |
| **仮シフト（draft）** | 黄系 | 店長が一度内容を確認し、調整中の状態 |
| **確定（approved）** | 緑系 | 正式に決定したシフト。従業員にも「確定」と表示される |

基本的な運用フローは次のとおりです。

```
[未確定] ──→ [仮シフト] ──→ [確定]
   │             │              │
   └────── 削除（ゴミ箱）／差し戻し で前段階に戻すことも可能
```

> **重要な原則**
> `未確定 → 確定` への直接昇格はできません。**必ず仮シフトを経由**します。
> これは、店長が一度全体を見渡してから確定する運用を強制するための仕様です。

---

## 2. ログイン

管理者権限（`role = admin`）のアカウントでログインすると、自動的に**シフト管理画面**が表示されます。
従業員アカウントとは表示画面が異なります。

---

## 3. 画面構成（タブ）

画面上部に 3 つのタブがあります。

1. **シフト一覧表** … 月単位のマトリックス。日々の運用の中心画面
2. **申請一覧** … 未確定（pending）申請のみを一覧表示。赤いバッジで件数表示
3. **ゴミ箱** … 削除済みシフトの確認・復元・完全削除

---

## 4. シフト一覧表タブ

従業員（行）×日付（列）のマトリックス形式でその月のシフト全体を表示します。

### 4.1 月の切り替え

中央の「**＜ 前月 / 次月 ＞**」ボタンで表示月を切り替えます。
切り替えと同時にその月のシフトデータが再取得されます。

### 4.2 セルの見方

| セルの内容 | 意味 |
| --- | --- |
| 灰色の `+` | シフト未登録（クリックで店長から仮シフト作成） |
| 赤色 + 「未確定」 | 従業員が申請したばかり |
| 黄色 + 「仮シフト」 | 店長が確認した仮の状態 |
| 緑色（バッジなし） | 確定済み |
| 「○○:○○ \| ○○:○○」 | 開始〜終了時間 |
| 「休」 | 休み希望 |

本日の列はうっすら紫色で強調されます。土曜日は青、日曜日は赤のヘッダー色です。

### 4.3 表示フィルター

「表示:」の行で、表示するシフトの状態を絞り込めます。

- すべて
- 未確定のみ
- 仮シフトのみ
- 確定のみ

絞り込みから外れたセルは `-` で表示されます。

### 4.4 単一セルの操作（通常モード）

#### 空セル（`+`）をクリック → 仮シフトを直接作成
店長判断でシフトを直接組みたいときに使います。
- 種類（出勤／休み）と、出勤の場合は時間を入力して「作成」を押す
- 作成されたシフトは **仮シフト（黄）** 状態になります

#### 既存セルをクリック → 状態に応じたモーダルが開く

**未確定（pending）の場合**
- 表示: 申請者名、日付、種類、希望時間
- 操作:
  - **削除** … ゴミ箱へ移動
  - **仮シフトにする** … 仮シフトに昇格（pending → draft）
- ※ 未確定から直接「確定」はできません。

**仮シフト（draft）の場合**
- 出勤／休みの切替、時間の編集が可能
- 操作:
  - **削除** … ゴミ箱へ移動
  - **未確定に戻す** … pending に差し戻し
  - **仮シフト更新** … 編集内容を保存（仮のまま）
  - **シフト確定** … 編集内容を保存しつつ確定（draft → approved）

**確定（approved）の場合**
- 内容は読み取り専用
- 操作:
  - **削除** … ゴミ箱へ移動
  - **仮シフトに戻す** … 修正したい場合の差し戻し（approved → draft）

---

### 4.5 一括選択モード

複数のシフトをまとめて操作したいときに使います。

#### 操作手順

1. 画面左上の「**一括選択**」スイッチをオンにします。
2. 操作したいセルを順にクリックします。**確定済みのセルは選択できません**（誤確定を防ぐため）。
3. 選択中のセルは青く点滅します。
4. 画面下部にフローティングバーが表示されます。

#### フローティングバーのボタン

選択内容によってボタン構成が変わります。

| 選択内容 | 表示されるボタン |
| --- | --- |
| すべて draft（仮シフト） | 削除 ／ 未確定に戻す ／ **シフト確定** |
| pending を含む（混在含む） | 削除 ／ **仮シフト化** |

> **設計意図**
> pending を含む選択では「シフト確定」ボタンは出ません。**必ず一度 draft を経由**させ、店長が改めて確定する運用に揃えています。

#### 一括確定／一括仮シフト化の時間入力

- 出勤シフトが含まれる場合、「**時間（出勤希望に適用）**」欄が表示されます。
- ここで入力した時間で、出勤の対象シフト全件の時間を**一括上書き**します。
- 全件休みのみであれば時間欄は表示されません。

> **注意**
> 元々個別に時間を持っていた場合も、一括操作では入力した時間に上書きされます。日ごとに時間を変えたい場合は、一括ではなく個別に対応してください。

---

### 4.6 「仮シフトを全て確定」ボタン

その月に仮シフト（draft）が 1 件以上ある場合のみ、画面右上に緑色のボタンが表示されます。

```
仮シフトを全て確定 (◯)   ← 括弧内は仮シフト件数
```

#### 動作

ボタンを押すと確認モーダルが表示され、「すべて確定する」を押すと次の処理が一度に行われます。

1. その月の **すべての仮シフト → 確定**
2. その月の **すべての未確定（pending）申請 → ゴミ箱へ移動**

#### 用途

月末の最終確定作業に使います。
未対応のまま残った申請は「店長が意図的に却下した」とみなしてゴミ箱に送り、月のシフトを完成させるための機能です。

> **注意**
> ゴミ箱に送られた未確定申請は**ゴミ箱タブから復元可能**ですが、従業員側からは見えなくなります。月末確定の前に申請一覧タブで未対応がないか必ず確認してください。

---

### 4.7 CSV 出力

「**CSV出力**」ボタンで、表示中の月のシフト表を CSV 形式でダウンロードできます。

- 出力対象は **確定（approved）シフトのみ**。仮シフト・未確定・ゴミ箱は含みません。
- ファイル名: `シフト表_yyyy年MM月.csv`
- 文字コード: UTF-8（BOM 付き、Excel 対応）
- 形式: 行＝従業員、列＝日（1日〜末日）、セル＝時間（`HH:MM〜HH:MM`）または「休」

---

## 5. 申請一覧タブ

未確定（pending）の申請のみを抜き出した一覧画面です。
タブの右肩に未対応件数が赤バッジで表示されます。

### 操作

各行の「**詳細**」リンクをクリックすると、シフト一覧表と同じ編集モーダルが開き、削除や仮シフト昇格が行えます。

> **使い方のコツ**
> 申請一覧タブを定期的に確認し、ここが空になっていれば「未対応の申請はゼロ」という運用がおすすめです。

---

## 6. ゴミ箱タブ

削除されたシフトを保管する場所です。`deleted_at` を持つ論理削除データのみ表示されます。
完全削除しない限り**いつでも復元可能**です。

### 6.1 フィルター

ゴミ箱内のデータが多い場合、3 つの条件で絞り込めます。

- **月** … 削除されたシフトの「対象日」の月（yyyy-MM）
- **従業員** … 対象従業員
- **削除日** … 削除した日（yyyy-MM-dd）

「**フィルターをクリア**」で全条件をリセットします。
画面右下に「表示中: ◯ / 全 ◯件」と件数が表示されます。

### 6.2 操作

#### 単一復元
各行の「**復元**」リンクで個別に復元します。
復元すると、削除前の状態（pending／draft／approved）でシフト一覧表に戻ります。

#### 一括操作
左側のチェックボックスで複数選択すると、画面右上にボタンが表示されます。

- **選択を復元** … チェックしたシフトをまとめて復元
- **完全削除** … チェックしたシフトをデータベースから物理削除（**取り消し不可**）

> **完全削除の注意**
> 確認モーダルで「※この操作は取り消せません。」と表示されます。古いデータの整理用途以外では基本的に使う必要はありません。

---

## 7. 画面遷移とメッセージ表示

操作の成功時、画面上部に緑色の通知が約 3 秒間表示されます。例:

- 「仮シフトを作成しました」
- 「シフトを確定しました」
- 「未確定に戻しました」
- 「シフトを削除しました（ゴミ箱から復元できます）」
- 「選択したシフトを完全削除しました」

エラー時はブラウザのコンソールにエラーが記録されます。何度繰り返しても操作が反映されない場合は、ページを再読み込みしてみてください。

---

## 8. 推奨される運用フロー（月次）

```
1. 月初〜月中
   ・従業員が出勤／休み希望を申請（pending）
   ・店長は「申請一覧タブ」を毎日チェック
   ・各申請を「仮シフトにする」で draft に移行（または不適なら削除）

2. 月末数日前
   ・「シフト一覧表」で全体バランスを確認
   ・必要に応じて空セルから店長判断で draft を追加作成
   ・時間調整は draft を直接編集
   ・一括選択で「シフト確定」してもOK（個別でも一括でもよい）

3. 月末（確定タイミング）
   ・申請一覧タブが空であることを確認
   ・残った draft は「仮シフトを全て確定」ボタンで一括確定
     （pending が残っていれば自動的にゴミ箱へ送られる）
   ・「CSV 出力」でシフト表を保存・配布
```

---

## 9. プロフィール / ログアウト

画面右上のメニューから、店長自身のプロフィール変更やログアウトが行えます。
従業員アカウントの追加・削除は本アプリの画面からはできません。必要な場合はシステム管理者にご相談ください。

---

## 10. よくある質問

**Q. 未確定申請を一気に確定したい。**
A. できません。一度「仮シフト化」してから確定してください。
月末であれば「仮シフトを全て確定」ボタンで未確定もまとめて整理できます（未確定はゴミ箱行きです）。

**Q. 確定したシフトを修正したい。**
A. 該当セルをクリックし「仮シフトに戻す」で draft に戻してから、時間や種類を編集して再度「シフト確定」してください。

**Q. 一括操作で時間を上書きしたくない。**
A. 出勤希望が含まれる一括操作では、入力した時間で**全件上書き**されます。個別の時間を維持したい場合は、1 件ずつ操作してください。

**Q. 完全削除した後で復元したい。**
A. **完全削除は取り消し不可**です。基本はゴミ箱に残しておき、必要時のみ完全削除してください。

**Q. 過去の月のシフトを修正したい。**
A. 月切替で過去月に移動して、通常通り編集できます（pending／draft／approved の状態遷移ルールは同じです）。

---

## 11. 困ったときは

- ボタンを押しても反応しない／表示が崩れる場合はブラウザの再読み込みをお試しください。
- データが意図せず消えた場合は、まず**ゴミ箱タブ**を確認してください。完全削除していなければ復元できます。
- アカウントの追加、システムエラーなどはシステム管理者にお問い合わせください。
